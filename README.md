# IS-2-1944



#¿Qué es? Es un algoritmo diseñado para encontrar el camino mas corto de un nodo a otro nodo mediante los pesos de las aristas usando estrategia voraz. 

#¿Para qué sirve? Si lo vemos como tiempo: Sirve para encontrar el camino que nos llevaria menos tiempo para de un punto tal llegar a otro punto.

#¿Cómo se implementa en el mundo? Actualmente los GPS utilizan este algoritmo para mostrar la ruta mas corta a algun destino que queramos ir como lo usa el google maps o waze.

#¿Cómo lo implementarías en tu vida? Precisamente como GPS pero en su version mas basica para aprender como funciona este algoritmo.

#¿Cómo lo implementarías en tu trabajo o tu trabajo de ensueño? Si tuviera una empresa de produccion de tal producto lo utilizaria para optimisar lo que es la logistica de el transporte de las materias primas para tal producto.
